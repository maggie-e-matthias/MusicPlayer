# Music Player 
A music player desktop app for playing local audio files using electron 

## Requirements 
* Node.js (LTS recommended)

## How to run 
1. Clone the repo 
    ```bash 
    git clone https://github.com/maggie-e-matthias/MusicPlayer.git
    cd MusicPlayer
    ```

2. Install dependancies 
    ```bash
    npm install
    ```

3. Run the app
    ```bash
    npm start
    ```
